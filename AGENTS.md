## antislop

Skills are installed in `.opencode/skills/`. Load the `antislop` core skill for any UI, copy, or code work in this project. The extra skills (`antislop-ui`, `antislop-copywriting`, `antislop-human`, `antislop-layoutmobile`, `antislop-code`) load only when the task needs them.

For visual work, read `DESIGN.md` for direction before applying the filter. antislop is a filter, not a source of direction. Close UI work with its Delivery Gate report.

Start each session by resolving antislop's usage mode (during or after).
